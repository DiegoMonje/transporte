# Transporte directo para empresas en Sevilla

Web corporativa B2B para servicios de transporte directo, urgente e industrial con base en Sevilla.

## Desarrollo

```bash
npm install
npm run dev
```

## Configuración pendiente

Los datos de teléfono, WhatsApp y email están centralizados en `app/site-config.ts`. Deben confirmarse antes de activar la captación real de solicitudes. El formulario incluye la experiencia visual y el estado de confirmación, pero requiere conectar un servicio de recepción antes de operar.

## Despliegue

El proyecto está preparado para Next.js y Vercel.
